This Privacy Policy explains how Thomas Percival handles information in connection with The Missing Walk iPhone application and this website.

Location information

The Missing Walk is a walking-based narrative investigation. The app uses device location permission to measure distance travelled so that investigation events can progress as the player walks.

The app is not designed to require visits to predetermined locations. Location is used for walking progression rather than route navigation.

Production verification required: the current project materials do not establish whether location information is transmitted off the device or retained beyond what is needed for the investigation experience. This policy must be updated to describe that behaviour accurately before release.

Investigation progress

The app includes persistence so that an investigation can be paused, resumed and restored. The exact production storage and data-handling behaviour should be confirmed against the final application before release claims are made about where that information is stored.

Audio
